# Moyao 个人简历网站

一个纯静态的单页简历站，视觉完全来自 `dist/assets/` 提供的设计图素材（1672×941 全景图）。

## 功能

- 进入网站静音自动播放 `去除水印.mp4`，播放结束自动进入静态主画面；视频加载失败时显示静态封面 `封面.png`；不显示额外的开场控制按钮。
- 主画面默认显示 `封面.png`。四张卡片热区悬停 / 聚焦时，切换到对应的 `01.png`、`02.png`、`03.png`、`04.png` 人物状态图，移开或失焦恢复封面；点击打开对应详情弹窗。
- 弹窗内容全部来自 `dist/assets/简历.docx`：项目经历、工作经历、GitHub 项目、技能工具，均按简历原文顺序展示，无虚构信息。
- 手机端底部提供 01–04 栏目入口按钮，热区同样可点；点击入口时先显示对应人物状态图再打开弹窗。
- 页面遵循系统 `prefers-reduced-motion` 设置，减少动态时会跳过开场过渡。

## 状态图切换

`01.png` ~ `04.png` 是提供的完整人物状态图，分别对应项目经历、工作经历、GitHub 项目和技能工具。
状态图只通过透明度切换，不进行中心点缩放。

## 本地预览

```powershell
python -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。

## GitHub 链接

简历中暂未提供仓库地址，因此当前弹窗不会编造链接；`repo(...)` 已支持传入真实 `url` 后渲染可点击仓库链接。
