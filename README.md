# Moyao 个人简历网站

一个纯静态的单页简历站，视觉完全来自 `dist/assets/` 提供的设计图素材（1672×941 全景图）。

## 功能

- 进入网站静音自动播放 `去除水印.mp4`，播放结束自动进入静态主画面；视频加载失败时显示静态封面 `封面.png`；开场可「跳过」。
- 主画面始终是封面设计图，人物不再切换状态。四张票券热区悬停 / 聚焦时，对应票券以自身为中心放大 7% 并带投影，移开恢复；点击打开对应详情弹窗。
- 弹窗内容全部来自 `dist/assets/简历.docx`：项目经历、工作经历、GitHub 项目、技能工具，均按简历原文顺序展示，无虚构信息。
- 手机端底部提供 01–04 栏目入口按钮，热区同样可点；点击入口时先放大票券再打开弹窗。

## 票券放大特效

`ticket-01.png` ~ `ticket-04.png` 是从封面里抠出的透明图层（生成脚本见 `.workbuddy/cut_tickets.py`），
所以放大时只放大票券本身，不会牵动人物和相邻票券。热区坐标与缩放中心均按设计图实测。

## 本地预览

```powershell
python -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。

## GitHub 链接

简历中暂未提供仓库地址，GitHub 弹窗仅展示项目介绍与技术栈。拿到真实仓库后，在 `dist/app.js` 的 `repo(...)` 处补充 `url`（或改造成 `<a class="m-link">`）即可。
